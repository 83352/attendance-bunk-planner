Add dark mode with sun-time default and header toggle

- globals.css fully tokenized: light theme keeps the retro paper look,
  new [data-theme="dark"] set switches to a dark terminal palette.
  Also defines --surface/--ink/--muted/--mint which newer admin and
  calendar styles referenced but were never declared.
- Inline pre-paint script picks the default by Indian sun time
  (dark 19:00-06:30, light otherwise); an explicit toggle choice in
  localStorage always wins. suppressHydrationWarning on <html>.
- ThemeToggle in the public header (useSyncExternalStore over a
  MutationObserver so no setState-in-effect); persists choice.
- Viewport themeColor now adapts to color scheme.
